# Calendário de Agendamentos para Manicures

Esta ferramenta oferece uma solução completa para gerenciamento de agendamentos de manicures, com visualizações diária, semanal e mensal para facilitar a organização dos compromissos.

## Funcionalidades

### Visão Diária
- Visualização detalhada dos agendamentos de um dia específico em formato de lista
- Seletor visual dos dias da semana para navegação rápida
- Ordenação por horário para fácil acompanhamento

### Visão Semanal
- Visualização hora a hora (das 8h às 20h) para cada dia da semana
- Identificação visual de horários ocupados e disponíveis
- Detalhes completos dos agendamentos ao clicar

### Visão Mensal
- Visão geral dos agendamentos do mês inteiro
- Indicador de quantidade de agendamentos por dia
- Lista detalhada de agendamentos ao clicar em um dia específico

### Formulário de Agendamento Especializado
- Seleção rápida de serviços comuns de manicure com valores sugeridos
- Opções de horários pré-definidos para facilitar a marcação
- Possibilidade de adicionar fotos de referência para inspirar o trabalho
- Seleção de cores para identificação visual dos agendamentos
- Campo para observações e detalhes específicos

## Design Responsivo
- Interface adaptável para diferentes tamanhos de tela
- Experiência otimizada para uso em dispositivos móveis
- Navegação simplificada com suporte a gestos de toque
- Elementos redimensionados para facilitar a interação em telas menores

## Como Usar

1. Selecione a visualização desejada (diária, semanal ou mensal)
2. Para adicionar um novo agendamento, preencha o formulário na parte inferior
3. Para ver detalhes de um agendamento, clique sobre ele na visualização
4. Para marcar um agendamento como concluído ou excluí-lo, use os botões no modal de detalhes

## Tecnologias Utilizadas

- Next.js para o frontend
- React Hooks para gerenciamento de estado
- date-fns para manipulação de datas
- Axios para requisições à API
- Estilização com CSS-in-JS (styled-jsx)
- react-icons para ícones
- Design responsivo com media queries

## Integração

Esta ferramenta está integrada ao backend existente da aplicação principal, utilizando a mesma API de agendamentos.
